## 💐 על הפרויקט

**פַרְחַנָא** הוא אתר חנות לבוטיק פרחים מבת-ים. הלקוחות בוחרים זר מוכן, מרכיבים זר משלהם פרח אחר פרח, או מוסיפים צמח ועציץ לבית. בסוף הם שולחים את ההזמנה המלאה ב-WhatsApp בלחיצה אחת. 🌷

כל האתר הוא **קובץ HTML אחד**, בלי שרת, בלי בילד ובלי התקנות. פותחים ועובד. 🪄

## 💬 איך עובדת ההזמנה?

```
🛒 בוחרים מוצרים   ➜   📝 ממלאים פרטי משלוח   ➜   💬 נפתח WhatsApp עם ההזמנה   ➜   ✅ העסק מאשר ומתאם תשלום
```

ככה נראית ההודעה שמגיעה לעסק:

```text
שלום פרחנא, אני רוצה להזמין:

• ורד אדום (פרח) × 6 = ₪90
• אדמונית (פרח) × 4 = ₪52

סה"כ מוצרים: ₪142

שם: ישראל ישראלי
טלפון: 050-1234567
כתובת למשלוח: הרצל 1, בת-ים
מועד משלוח: יום שני, 2.11.2026, 12:00-15:00
ברכה: מזל טוב! 🎉
```

לפני השליחה האתר בודק שלא חסר כלום: שם, טלפון תקין, כתובת, תאריך, שעה ומינימום 10 פרחים בהרכבה עצמית. ✔️

## 🛠️ התאמה אישית

### 📞 שינוי מספר ה-WhatsApp
ב-`index.html` מחפשים את `BUSINESS`:

```js
const BUSINESS = {
  whatsapp: "972528754441", // מספר בפורמט בינלאומי, בלי 0 בהתחלה
  minFlowers: 10            // מינימום פרחים בהרכבה עצמית
};
```

### 🌼 הוספת מוצר
כל מוצר הוא שורה אחת ברשימה המתאימה (`readyBouquets`, `flowers`, `plantItems`, `vesselItems`):

```js
["שם המוצר", 250, "תיאור קצר", img("מזהה-תמונה-ב-Unsplash"), "romantic 200to300"]
//  שם        מחיר   תיאור         תמונה                         תגיות סינון (לזרים בלבד)
```

🏷️ **תגיות סינון לזרים:** `romantic` · `birthday` · `luxury` · `white` · `under200` · `200to300` · `over300`
